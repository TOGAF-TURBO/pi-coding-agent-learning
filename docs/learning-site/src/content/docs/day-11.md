## 核心概念

**差异渲染（Diff Rendering）**：TUI 引擎不重绘整个屏幕，而是比较前后两帧的差异，只更新变化的部分。这比全屏重绘效率高几个数量级，也是 pi 在终端中流畅运行的基础。

**组件树**：所有 UI 元素都是 `Component` 接口的实现。`Container` 可以嵌套子组件形成树结构。焦点管理通过 `Focusable` 接口实现，支持 Tab 键在可聚焦组件间切换。

**渲染循环**：`start()` 启动主循环——监听键盘/鼠标事件、更新组件状态、计算差异、输出到终端。

**浮层系统**：`showOverlay()` 在现有 UI 上叠加浮层（对话框、下拉框、自动补全菜单），浮层具有独立的渲染和事件处理。
